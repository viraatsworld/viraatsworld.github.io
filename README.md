# viraatsworld.github.io

Personal portfolio of Viraat Saaran: Robotics Software Engineer (ROS 2 · Motion Planning · Reinforcement Learning).

Plain HTML/CSS/vanilla JS, no build step. Push to `main` and GitHub Pages serves the root folder.

- `index.html`: the one-page site
- `assets/css/style.css`: styles (light/dark via `prefers-color-scheme` + manual toggle)
- `assets/js/main.js`: theme, profile lens, nav, scroll reveals, copy-email
- `assets/js/robot.js`: interactive pick-and-place arm in the hero
- `assets/cv/Viraat_Saaran_CV.pdf`: downloadable CV (add it)

**Profile lens:** `?lens=ai` opens the AI & Simulation view, and no parameter opens the Robotics view.

Preview locally: `python3 -m http.server` then open http://localhost:8000
